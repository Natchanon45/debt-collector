# Phase 6.9 Field Align & Signature Name Placement

ปรับเฉพาะข้อความสีน้ำเงินที่ถูกกรอกลงบนฟอร์มพื้นหลัง โดยไม่แก้ไขฟอร์ม PNG สีดำ

## Changes
- จัดตำแหน่งเริ่มต้นของ ลำดับที่ / ทำที่ / วันที่ ให้ยึดแกน X เดียวกันจากช่องลำดับที่
- จัดข้อมูลที่กรอกให้อยู่กึ่งกลางของเส้นฟอร์มโดยคำนวณจากพื้นที่ `maxWidth`
- ยกเว้นจำนวนเงิน ให้ชิดขวาของเส้นเพื่อป้องกันการแก้ไขตัวเลข
- ขยับเลขบัตรประชาชนผู้ให้กู้ไปทางขวา
- ย้ายชื่อในวงเล็บของผู้ลงลายเซ็นทุกตำแหน่งไปไว้ใต้เส้น
- คงลายเซ็น PNG ให้อยู่เหนือเส้นและกึ่งกลางช่อง
- ลดขนาดชื่อใต้ลายเซ็นให้ไม่ยาวเกินเส้น
- อัปเดต cache เป็น `phase6-9-field-align`
