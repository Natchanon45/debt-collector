# Phase 6.7 Signature Engine

ปรับระบบลายเซ็นสำหรับ PDF template แบบพื้นหลังภาพ

## สิ่งที่แก้

- เพิ่ม Signature Engine สำหรับ crop ลายเซ็นอัตโนมัติหลังเซ็นบน canvas
- แปลงลายเซ็นเป็น PNG โปร่งใส และตัดพื้นที่ว่างรอบลายเซ็นออก
- วางลายเซ็นตามตำแหน่ง fixed x,y บนฟอร์ม A4
- จัดกึ่งกลางลายเซ็นในกรอบของแต่ละช่องโดยรักษาอัตราส่วน ไม่ยืดภาพ
- เก็บลายเซ็นลงใน `contracts.signatures` แยกตามตำแหน่ง
  - `borrower`
  - `lender`
  - `witness1`
  - `witness2`
  - `writer`
- เมื่อเปิดแก้ไขสัญญา ระบบดึงลายเซ็นเดิมกลับมาแสดงใน canvas
- อัปเดต service worker cache เป็น `phase6-7-signature-engine`

## ตำแหน่งลายเซ็นใน PDF

- ผู้กู้: ช่องซ้ายแถวแรก
- ผู้ให้กู้: ช่องขวาแถวแรก
- พยาน 1: ช่องซ้ายแถวสอง
- พยาน 2: ช่องขวาแถวสอง
- ผู้เขียนและพยาน: ช่องซ้ายแถวสาม

## ไฟล์ที่แก้

- `assets/js/app.js`
- `service-worker.js`
