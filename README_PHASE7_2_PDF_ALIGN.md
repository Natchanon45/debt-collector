# Phase 7.2 - PDF Contract Alignment Fix

ปรับแก้ตามคำขอ:

1. ปรับเส้นช่องกรอกส่วนหัวของแบบฟอร์ม PDF ให้เริ่มแกน X ตรงกันสำหรับ ลำดับที่ / ทำที่ / วันที่
2. ปรับค่าที่เติมลงบนเส้นให้จัดกึ่งกลางเส้นเป็นค่าเริ่มต้น
3. คงข้อยกเว้นช่องจำนวนเงินให้ชิดขวาสุดของเส้น เพื่อช่วยลดความเสี่ยงการเติมตัวเลขเพิ่ม
4. ปรับตำแหน่งชื่อในวงเล็บใต้เส้นลายเซ็นให้ต่ำกว่าเส้นชัดเจนขึ้น โดยให้เฉพาะภาพลายเซ็นอยู่เหนือเส้น
5. ปรับหน้าตาอัปโหลดเอกสารลูกหนี้ไม่ให้แสดงชื่อไฟล์เต็มใน dropzone ระหว่างเลือกไฟล์ แต่แสดงเป็นจำนวนไฟล์แทน
6. เพิ่ม cache version ของ Service Worker และ template image เพื่อให้ browser โหลดไฟล์แก้ไขใหม่
