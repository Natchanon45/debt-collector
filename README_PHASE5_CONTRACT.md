# Debt Collector Phase 5 - Contract System

สิ่งที่เพิ่มในเวอร์ชันนี้

- เพิ่มแท็บ “สัญญา” ที่ Bottom Navigation
- สร้างสัญญากู้ยืมเงินจากข้อมูลลูกหนี้
- เพิ่มฟอร์มผู้ให้กู้ จำนวนเงิน วันทำสัญญา วันครบกำหนด ดอกเบี้ย เงื่อนไข และพยาน
- เซ็นลายเซ็นบนหน้าจอด้วย Canvas 4 ช่อง: ผู้ให้กู้, ผู้กู้, พยาน 1, พยาน 2
- สร้าง PDF ภาษาไทยโดยใช้ html2canvas + jsPDF
- บันทึก PDF เข้า Firebase Storage ที่ `users/{uid}/debtors/{debtorId}/contracts/`
- บันทึก metadata ลง Firestore ใน `documents` และ `contracts`
- แสดงรายการสัญญาและเปิด PDF ได้จากแท็บสัญญาและรายการเอกสาร
- ปรับ Service Worker cache version เป็น `phase5-contract-v1`

ไฟล์ที่แก้ไข

- `index.html`
- `assets/js/app.js`
- `assets/css/style.css`
- `service-worker.js`

หมายเหตุ

แม่แบบสัญญานี้เป็นแบบฟอร์มทั่วไปสำหรับบันทึกหลักฐานการกู้ยืม ควรตรวจทานชื่อ เลขบัตร ที่อยู่ จำนวนเงิน วันครบกำหนด ดอกเบี้ย และเงื่อนไขก่อนใช้งานจริง


## Phase 5.2 Contract Hotfix
- บันทึกชื่อผู้ให้กู้และที่อยู่ผู้ให้กู้ลง settings/profile ใน Firestore/local storage
- แก้เมนูธุรกรรมให้กดได้ด้วย delegated navigation ที่ตรวจ panel เป้าหมายโดยตรง
- ปรับเมนูล่างเป็นแผงเดียว fixed bottom แสดงตลอดเวลา active สีเขียวเข้ม inactive สีจาง
- ปรับ PDF เป็นฟอนต์ TH Sarabun/Sarabun 14px ทั้งเอกสาร
- ข้อมูลที่ระบบกรอกลงสัญญาเป็นตัวหนาสีน้ำเงินและขีดเส้นใต้
- วันที่แสดงภาษาไทย พ.ศ. เช่น 16 ก.ค. 2569
- สถานที่ทำสัญญาขึ้นย่อหน้าใหม่
- ไม่ซ่อนเลขประจำตัวประชาชนในสัญญา
- ลายน้ำอยู่ด้านล่างสุด ตัวเล็ก
