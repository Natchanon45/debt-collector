# Phase 6.11 Smart Alignment + Signature Tighten

- เพิ่ม Smart Alignment Rule สำหรับข้อความบนเส้นฟอร์ม
  - ข้อความยาว >= 50% ของเส้น: จัดกึ่งกลาง
  - ข้อความสั้น < 50% ของเส้น: ชิดซ้ายพร้อมเว้นระยะเล็กน้อย
  - จำนวนเงิน: ชิดขวาเหมือนเดิม
- ลดขนาดลายเซ็นและขยับตำแหน่ง Y ลง ให้ลายเซ็นชิดเส้นมากขึ้น
- ลดขนาดชื่อใต้ลายเซ็นอีกเล็กน้อย
- ไม่แก้ภาพฟอร์มพื้นหลังและไม่แก้ข้อความฟอร์มสีดำ
