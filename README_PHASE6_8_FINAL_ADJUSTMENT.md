# Phase 6.8 Final PDF Adjustment

ปรับเฉพาะพิกัดข้อความและลายเซ็นบน PDF template โดยไม่เปลี่ยนภาพฟอร์มพื้นหลังและไม่ลดจำนวนข้อสัญญา

## Changes
- ที่อยู่ผู้กู้เริ่มต่อจากคำว่า “ที่อยู่” ในบรรทัดเดียวกับชื่อ/อายุ และค่อยขึ้นบรรทัดใหม่เมื่อยาวเกินช่อง
- เลขบัตรประชาชนผู้ให้กู้ขยับไปทางขวาเฉพาะข้อมูลที่กรอก
- ลดขนาดข้อความสีน้ำเงินที่กรอกลงใน PDF ทั้งเอกสาร
- ลายเซ็น PNG วางเหนือเส้นและจัดกึ่งกลางช่อง
- ชื่อใต้ลายเซ็นลดขนาด ใส่วงเล็บ และจัดกึ่งกลางใต้เส้น
- ชื่อผู้เขียนและพยานลดขนาดเพิ่มเพื่อไม่ให้ยาวเกินเส้น
- อัปเดต Service Worker cache เป็น phase6-8-final-adjustment
